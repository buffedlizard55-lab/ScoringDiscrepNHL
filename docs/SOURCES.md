## 5. API and tooling references (for the monitor)

- ✅ Live data: NHL web API `https://api-web.nhle.com/v1/...` (score, gamecenter boxscore & play-by-play). Official NHL property; endpoints and response fields verified against:
  - [pseudo-r/Public-NHL-API](https://github.com/pseudo-r/Public-NHL-API) (endpoint reference with live probes, retrieved 2026-10-07)
  - [Zmalski/NHL-API-Reference](https://github.com/Zmalski/NHL-API-Reference) (unofficial NHL API reference)
- Legacy API `statsapi.web.nhl.com` was decommissioned ~2023 — do not use.
- Historical stats REST API: `https://api.nhle.com/stats/rest` (boxscore-level data back to 1917-18).
- Historical play-by-play limits: NHL RTSS launched 2007-08; machine-readable JSON feeds are strongest from ~2010-11 — see [Puck Over the Glass — A Brief History of NHL Play-by-Play Data](https://puckovertheglass.substack.com/p/a-brief-history-of-nhl-play-by-play) and [hockeyR](https://hockeyr.netlify.app/).

## Verification policy

1. Transcribe only what a linked source literally states; `null` over guessing.
2. Prefer NHL.com / NHL PR; mark anything else `verified_secondary`.
3. Flag missing pieces explicitly in `evidence_notes` (e.g., "period not stated in source").
4. One record = one documented change event, with both the original and corrected state preserved.
