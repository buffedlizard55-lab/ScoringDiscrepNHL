Every change to the official scoring record — captured, explained, sourced.

This project tracks events where the NHL's official scoring record was later changed: goals waved off after video review, reviews that reinstated goals, scorer and assist corrections made in-game or after the final buzzer, and league-acknowledged review errors. Every record links to its official source. An automatic monitor snapshots the official NHL API and flags new discrepancies as they happen.

Monitor & detection — what can and cannot be caught automatically

✅ Detectable automatically

  • In-game review overturns (goal → no-goal). When the Situation Room waves off a goal, the official play-by-play and team totals are updated in place. The monitor keeps its own snapshot, so the disappearance of a goal event (or a score dropping) is caught within one polling cycle (15 minutes via GitHub Actions; near-realtime if run tighter).
  • Reviews that add a goal back. A goal event appearing that wasn't in the previous snapshot is flagged, including the rare no-goal → goal double reviews.
  • Scorer & assist re-credits, during or after the game. The NHL publishes postgame “OFFICIAL SCORING CHANGE” decisions (via NHL Public Relations). In the data feed these show up as the same goal event with a different scorer/assist — the monitor diffs exactly those fields.
  • Postgame boxscore edits. Re-checking finished games for several days catches corrections that land after the final buzzer.

⚠️ Not detectable automatically (human work)

  • The reason behind a change. The feed shows that the record changed, never why. Classification (video review vs. scorer judgment) requires reading the NHL Situation Room post or NHL PR announcement.
  • There is no official corrections feed. The NHL updates records in place and does not publish a change log. Scorer decisions announced only via NHL PR on X are not carried by the stats API at all.
  • Retroactive fixes made before monitoring started (and any correction made between two snapshots if the snapshot store is lost).
  • Cases resolved only in media coverage (e.g., a goal that “should have counted” but was never restored to the record) — these are found by research, not by polling.
  • Ambiguous events like shot/blocked-shot reclassifications, which this project intentionally scopes out.

How the pipeline works

  1. A GitHub Actions workflow (.github/workflows/nhl-monitor.yml) runs monitor/nhl_monitor.py every 15 minutes plus a daily audit.
  2. The script reads today's and recent games from the official API (api-web.nhle.com/v1/score/… and /v1/gamecenter/{id}/play-by-play) and normalizes every goal event.
  3. Each normalized state is diffed against the previous snapshot stored in data/snapshots/; changes become alerts in data/alerts/feed.json (rendered above) and commit back to the repo.
  4. A human reviews each alert against official NHL.com / NHL PR posts and, when verified, adds it to data/discrepancies.json with source links.

Latency: in-season, in-game changes are caught within the polling interval (15 min here). Postgame changes usually land within minutes to ~24 hours of the final buzzer. Historical coverage below was built by manual research, not by the monitor.

Sources, coverage & limitations

Primary sources used

  • NHL.com “Situation Room” posts — the league publishes an explanation for coach's challenges and Situation Room-initiated reviews. These are the authoritative record for in-game goal/no-goal changes. Example: 2024 Cup Final Game 6.
  • NHL Public Relations (@NHLPR) “OFFICIAL SCORING CHANGE” posts on X — the league's channel for postgame scorer/assist corrections. Example: Bruins–Devils, April 8, 2025.
  • Official NHL statements acknowledging review errors, e.g. Avalanche–Blues, Oct. 19, 2017.
  • NHL web API (api-web.nhle.com) — live scores, boxscores and play-by-play used by the monitor.
  • For each record, the full link list with per-source notes is in docs/SOURCES.md and in the CSV at data/discrepancies.csv.

Coverage limitations (be honest, be explicit)

  • Historical depth is uneven. Detailed event-level (play-by-play) data from the NHL's Real Time Scoring System exists from the 2007-08 season; machine-readable JSON feeds are strongest from ~2010-11 onward. Boxscore-level data goes back to 1917-18. Therefore in-game review discrepancies are only systematically capturable from the video-review era (coach's challenges began 2015-16; the Situation Room launched 2011-12), and scorer-correction records rely on whatever documentation survived in newspapers and team media for older games.
  • This database is a growing sample, not a census. Early eras (1917–2007) contain only discrepancies with surviving verifiable documentation (see records from 1977, 1987, 2004). We never infer records from memory or fill gaps with assumptions.
  • Postgame corrections are under-counted everywhere — the NHL publishes “OFFICIAL SCORING CHANGE” notices on X, but there is no searchable archive; this project archives them record-by-record as they are found.
  • Records with secondary-only evidence are explicitly flagged (evidence_status: verified_secondary) instead of being silently accepted.
