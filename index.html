Sources & method

Every record links to the official source that supports it. The monitor snapshots official NHL data every 30 minutes and treats any difference between snapshots as a discrepancy — diff-first detection — so it catches corrections even when they are never announced.

Official sources used

  • Live feed (statsapi v1) — statsapi.web.nhl.com/api/v1/game/{gamePk}/feed/live: authoritative play-by-play, goals, review events.
  • Schedule API (statsapi v1) — statsapi.web.nhl.com/api/v1/schedule: which games are final, final scores.
  • Official game reports (PDF) — nhl.com/scores/htmlreports/{season}/GS|ES{report}.PDF: hash-monitored for silent edits.
  • NHL Situation Room — nhl.com/news/topic/situation-room: official explanations of review outcomes.
  • NHL Records — records.nhl.com: historical verification (manual).

How records are classified

  • Changed goal totals — goal ↔ no-goal; these carry the settlement risk badge.
  • Attribution-only — scorer/assist/strength corrections; the goal total is untouched.
  • Evidence status — verified incomplete conflicting unavailable; any non-verified evidence flags the record for human review.

Rules this site is built on

  • No record without official-source evidence links. No invented fields — unknown values stay empty.
  • Both the original and corrected states are always shown.
  • Automation detects; humans confirm. Every automated record starts as pending review.
